# 🛒 Olist E-Commerce Analytics

## 📊 Project Overview

The **Olist E-Commerce Analytics Project** analyzes Brazilian e-commerce data to uncover insights into **sales, customers, products, sellers, payments, orders, delivery performance, and customer reviews**.

The project follows an end-to-end data analytics workflow using **Python, SQL, Power BI, and Tableau**, transforming raw e-commerce data into meaningful business insights and interactive dashboards.

## 🎯 Objectives

* Analyze overall e-commerce sales performance.
* Identify top-performing product categories.
* Analyze customer purchasing behavior.
* Evaluate seller performance.
* Understand payment method preferences.
* Analyze order and delivery trends.
* Evaluate customer review scores.
* Identify trends and opportunities through dashboards.
